## 1. Чтобы заказ приходил сообщением на телефон

Номер кафе **+7 (900) 473-20-35** уже стоит на сайте везде: в шапке, в подвале, на странице оформления и в тексте заказа.

### Вариант A — уже работает (0 минут настройки)
После оформления заказа на экране «Заказ принят» появляются кнопки:
- **«Отправить в WhatsApp»** — открывает чат с номером кафе, в котором уже готовый текст заказа (состав, пожелания, адрес, сумма);
- **«Отправить SMS»** — то же самое через сообщения;
- **«Скопировать заказ»** — вставить в любой мессенджер.

Гость нажимает одну кнопку — заказ приходит вам. Минус: инициатива на госте.

### Вариант B — автоматически (5–10 минут, бесплатно)
Заказ уходит сам, без участия гостя: на телефон (Telegram / WhatsApp / почта). Делается через «вебхук».
Подойдёт любой сервис, принимающий POST-запрос: Google Apps Script, Formspree, n8n, ваш бот.

**Пошагово через Google Apps Script:**
1. Откройте [script.google.com](https://script.google.com) → «Новый проект».
2. Вставьте код:
   ```javascript
   function doPost(e) {
     var d = JSON.parse(e.postData.contents);
     var text = d.text || JSON.stringify(d.order);
     // 1) в Telegram (если нужен) — укажите свой токен бота и chat_id:
     // var TG_TOKEN = '123456:ABC...'; var CHAT_ID = '123456789';
     // UrlFetchApp.fetch('https://api.telegram.org/bot' + TG_TOKEN + '/sendMessage',
     //   { method:'post', payload:{ chat_id: CHAT_ID, text: text } });
     // 2) письмо на почту:
     MailApp.sendEmail('ВАША_ПОЧТА@mail.ru', 'Новый заказ с сайта «Колобок»', text);
     return ContentService.createTextOutput('ok');
   }
   ```
3. «Развернуть» → «Новое развёртывание» → тип «Веб-приложение» → доступ «Все, у кого есть ссылка» → Развернуть.
4. Скопируйте ссылку вида `https://script.google.com/macros/s/AKfy.../exec`.
5. На сайте нажмите **⚙** (левый нижний угол) → поле **«Куда присылать заказы автоматически (вебхук)»** → вставьте ссылку → Сохранить.

Всё: теперь каждый заказ и каждое сообщение из формы на странице «Контакты» уходит вам автоматически, а на экране успеха появится подпись «Заказ уже ушёл автоматически».

**Чтобы получать заказы в Telegram:** создайте бота у [@BotFather](https://t.me/BotFather), узнайте свой `chat_id` у [@userinfobot](https://t.me/userinfobot) и раскомментируйте блок с `api.telegram.org` в коде выше.

### Вариант C — «по-взрослому» (когда будет время)
Свой небольшой сервер (Node/PHP на хостинге) или сервис заказов: заказы в базе, статусы «принят → готовится → в пути», SMS клиенту, уведомления администратору. Это уже этап доработки — могу сделать отдельно.

## 2. ЮKassa (онлайн-оплата картой)

Сейчас оплата в **демо-режиме**: поля карты есть, деньги не списываются. Код уже подготовлен под ЮKassa.

### Что понадобится
- ИП или ООО (ЮKassa работает только с юрлицами/ИП);
- договор с ЮKassa → **shopId** и **секретный ключ**;
- онлайн-касса (по 54-ФЗ) — ЮKassa может сама формировать чеки, это удобнее;
- подтверждённый домен сайта.

### Как выглядит схема подключения
1. Гость нажимает «Оплатить» → браузер отправляет состав заказа **на ваш сервер** (или в облачную функцию).
2. Сервер запрашивает у ЮKassa платёж: `POST https://api.yookassa.ru/v3/payments` с `shopId` + `secretKey`, суммой и `return_url`.
3. ЮKassa возвращает ссылку `confirmation_url` — браузер гостя переходит туда, гость платит.
4. ЮKassa присылает вам **webhook** `payment.succeeded` — на этом этапе заказ уходит на телефон/кухню.
5. Гость возвращается на сайт на экран «Заказ принят» с чеком.

### Что уже готово в коде
- Константа `PAY` в `build/site.js` (`assets/js/site.js` на сайте): переключатель `provider: 'demo' | 'yookassa'`, поля `yookassaShopId`, `yookassaReturnUrl`.
- Способ оплаты «Картой онлайн» и подпись «· ЮKassa» на экране оплаты.
- Экран успеха, текст заказа, отправка на телефон — всё работает и без оплаты.

### Что нужно дописать (это уже работа с сервером/ключом)
1. Небольшая функция на сервере: создание платежа + подпись запроса.
2. В блоке оплаты на сайте: заменить демо-поля на вызов этой функции и переход на `confirmation_url`.
3. Настроить webhook `payment.succeeded` → отправка заказа на телефон и повтор вызова `sendOrderToOwner()`.

Когда будете готовы — пришлите `shopId` (секретный ключ не присылайте в чат: он вставляется только на сервере), и я допишу оплату под ваши доступы.

## 3. Как выложить сайт в интернет

1. **Домен** — например `kolobok-udomlya.ru` (200–300 ₽/год у любого регистратора).
2. **Хостинг** — самый простой путь: [Netlify Drop](https://app.netlify.com/drop) или Cloudflare Pages: перетащите **папку `site`** (или архив `kolobok-site.zip`) в окно браузера — сайт сразу опубликуется.
   Обычный хостинг с панелью тоже подойдёт: закиньте содержимое папки `site` в корень сайта, чтобы `index.html` лежал в корне.
3. **HTTPS** — включается автоматически на Netlify/Cloudflare; на обычном хостинге — бесплатный сертификат Let's Encrypt в панели.
4. **Ссылку добавьте** в Яндекс.Бизнес и 2ГИС — это бесплатный поток заказов из карт.
5. Проверьте на телефоне: заказ → WhatsApp → звонок.

> Сайт одним файлом (`kolobok-udomlya.html`) удобно отправлять в мессенджерах и открывать без интернета — но для хостинга используйте папку `site` (многостраничную).
