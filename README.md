# Сайт кафе «Колобок» — Удомля

Интернет-магазин для кафе «Колобок»: гость выбирает блюда, пишет пожелания, собирает свою шаурму,
оформляет доставку или самовывоз и оплачивает заказ. Сайт **многостраничный**.

Что где лежит:
| Что | Для чего |
|---|---|
| **`site/`** | многостраничная версия для хостинга: `index.html`, `menu.html`, `delivery.html`, `about.html`, `contacts.html`, `checkout.html` + `assets/` |
| **`kolobok-site.zip`** | тот же сайт архивом — удобно отдать верстальщику/залить на хостинг |
| **`kolobok-udomlya.html`** | весь сайт одним файлом (все страницы внутри, навигация по `#/меню`) — открывается двойным кликом, работает без интернета |
| **`ПОДКЛЮЧЕНИЕ.md`** | инструкции: как заказы приходят на телефон и как подключить ЮKassa |

## 🎵 Песня «Колобок 2.0» на сайте

Весёлая песня кафе (женский голос) встроена в сайт: **клик по крутящемуся Колобку в шапке** (или по большому Колобку на главной) — и она играет. Колобок пускается в пляс, летят ноты, внизу появляется мини-плеер с перемоткой, громкостью и повтором, а на экране «Заказ принят!» есть кнопка с коротким джинглом. Автоплея нет специально — браузеры его блокируют.

- Как менять песню, громкость, джингл → **ПЕСНЯ_НА_САЙТЕ.md**
- Исходники звука → `assets-src/audio/` (kolobok-song.mp3, kolobok-jingle.mp3, song-bundle.mp3, cover.jpg)
- Сборка: `python3 build_site.py` — звук сам разложится по сайту, попадёт в архив и вшивается в однофайловую версию

## 2. Что уже работает на сайте

**Заказ и оплата (главная задача):**

- **конструктор «Своя шаурма»**: размер, мясо (курица/говядина/микс/без мяса), до 2 соусов, до 5 начинок, острота, «убрать из состава» + пожелание; цена считается на лету;
- **заказ уходит на телефон заведения `+7 (900) 473-20-35`**: кнопки «Отправить в WhatsApp» / «Отправить SMS» с готовым текстом заказа, плюс автоматическая отправка на вебхук (настраивается в панели ⚙, инструкция — в `ПОДКЛЮЧЕНИЕ.md`);
- каталог из 25 позиций в 7 категориях (включая реальную **куру-гриль** и оладушки из отзывов): хиты, шаурма, бургеры и хот-доги, закуски, выпечка, комбо, напитки;
- карточка блюда: размер (стандарт / большая / XL), острота, платные добавки (двойной сыр, бекон, доп. мясо…), «убрать из состава» (без лука, без соуса…), количество;
- корзина с сохранением между визитами, промокоды (`ПЕРВЫЙ` −15 %, `КОЛОБОК10` −10 %);

## 3. Как посмотреть и как менять

Посмотреть: открыть `kolobok-udomlya.html` в браузере (телефон/компьютер) — это самодостаточный файл.

Быстро поменять контакты и условия: панель **⚙** на сайте.

Поменять меню, цены, тексты всерьёз:
```
build/                 ← исходники
  partials.html        ← общие части: шапка, подвал, корзина, модалки (с маркерами @head/@header/@footer/@overlays)
  page_index.html      ← содержимое страниц (по файлу на страницу)
  page_menu.html  page_delivery.html  page_about.html  page_contacts.html  page_checkout.html
  site.css             ← стили и анимации
  site.js              ← настройки (SETTINGS), меню (PRODUCTS), конструктор (BUILDER), корзина, заказ
  fonts.css            ← вшитые шрифты (base64)
  img/                 ← фото для меню и галереи (jpg)
  test2.js             ← автотесты (jsdom): навигация, конструктор, пожелания, отправка заказа
assets/ real/          ← исходные фото
build_site.py          ← сборка: python3 build_site.py → site/ + kolobok-udomlya.html + kolobok-site.zip
ПОДКЛЮЧЕНИЕ.md         ← заказы на телефон + ЮKassa + как выложить
```
Пересборка после любых правок: `python3 build_site.py`, затем `node build/test2.js` (14 проверок).
В `build/site.js` меню задаётся массивом `PRODUCTS` — одна строка на позицию
(`name`, `desc`, `price`, `w` — вес, `img` или `emoji`, `badge`, `opts`). Цены и состав правятся в одну строку.

## 4. Как выложить в интернет

1. Купить домен (например, `kolobok-udomlya.ru`) — 200–300 ₽/год.
2. Хостинг: подойдёт бесплатный Netlify / Vercel / Cloudflare Pages (перетащить файл) либо обычный хостинг с панелью — там просто положить `index.html`.
3. Включить HTTPS (везде включён по умолчанию) — без него браузеры ругаются на формы и оплату.
4. В Яндекс.Бизнес и 2ГИС добавить ссылку на сайт — бесплатный приток заказов из карт.
5. Проверить на телефоне реального гостя: заказ → WhatsApp → звонок.

## 5. Что доработать для «боевого» режима (по этапам)

**Этап 1 — заказы на телефон (0–10 минут).** Кнопки WhatsApp/SMS уже работают. Чтобы заказы шли автоматически —
вставьте вебхук в панели ⚙ (пошагово в `ПОДКЛЮЧЕНИЕ.md`, бесплатно через Google Apps Script → Telegram или почта).

**Этап 2 — настоящая оплата (3–5 дней).** Интернет-эквайринг ЮKassa: договор ИП/ООО, онлайн-касса для чеков (54-ФЗ), тестовые платежи.
В коде уже готов переключатель `PAY.provider` и подписи ЮKassa — останется добавить создание платежа на сервере (схема в `ПОДКЛЮЧЕНИЕ.md`).

**Этап 3 — доставка.** Карта зон доставки (район → своя цена/время), выбор времени «ко времени», смс/пуш курьеру, статус «курьер выехал».

**Этап 4 — рост.** Личный кабинет и бонусы «Колобок-баллы», повтор последнего заказа в один клик, PWA-приложение на телефон («Добавить на главный экран»), отзывы с фото, акции по дням недели, интеграция с Яндекс.Едой/Delivery для дополнительного потока.

## 6. Юридические мелочи

В подвале есть шаблонные «Условия заказа» и «Политика конфиденциальности» (модальные окна).
Перед запуском: указать реальные реквизиты ИП/ООО, ИНН, адрес, обновить текст политики под фактическую обработку данных (имя, телефон, адрес доставки) и подключить чекбокс согласия — он уже есть в форме заказа.
